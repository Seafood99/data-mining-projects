# 📊 Data Mining Projects

This repository is a collection of data mining mini-projects completed as part of coursework and personal experiments.

## 📁 Projects

### [🎶 K-Pop Song Ranking Classifier](https://github.com/Seafood99/K-Pop-Song-Ranking-Classifier)
A machine learning project that predicts song ranking using text-based features from song titles and artists. TF-IDF + Random Forest + Feature Selection (MI & Chi-Square).

### [🌰 Pistachio Image Texture Analysis](https://github.com/Seafood99/pistachio-image-mining)
An image processing project that extracts texture features from pistachio images using GLCM (Gray-Level Co-occurrence Matrix).

## 🔧 Tools Used
- Python
- Scikit-Learn
- Scikit-Image
- Pandas
- Matplotlib
- Jupyter Notebook
